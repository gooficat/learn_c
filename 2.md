### Setting up the C language on your computer

In this chapter you will be walked through the steps of setting up your computer for programming in C. There are separate instructions for different systems. 

A *compiler* is a tool that turns your code into machine code. Traditionally there are multiple steps. I will list them but they will be explained later on.

preprocessing
compilation
assembly
linkage

Most modern "compilers" actually do all of these steps together.

We will use a compiler called Clang. This is a compiler built on LLVM which is a tool that generates optimized machine code from a special in-between language. Usually it comes with LLVM along with a number of other related tools.

The other tools that we need are:

- A version / backup system. This is non-negiotiable. You need some way to keep your code safe, and a way to check older versions of your code in case you break something. In this tutorial we will use Git. This is a version control tool developed by Linus Torvalds, creator of the Linux kernel. It is extremely popular and there are many free websites for hosting a backup of your code online.

- Some form of code editor. My two recommendations are Helix and Visual Studio Code. The latter is easier if you aren't used to terminal or keyboard-based interfaces, but I do recommend giving Helix a shot.

Technically you could edit code in any plain text editor, even Notepad if you wanted, but it's just far more convenient to have auto-complete, color-coding, line-numbers and proper indenting.


## Setting up the Command Line tools.

### Windows:

On Windows, my recommendation is to use MSYS2, which is a special, self-contained environment that allows you to run POSIX programs (the same interface style as Linux) on Windows.

<https://msys2.org>

Once it is installed, open a CLANG64 shell, and run these.
Each will give a confirmation prompt, where you need to type `y` and press Enter.

``pacman -Syu``
Then, restart the terminal window by closing and re-opening another one.
``pacman -S llvm lldb git``
If using Helix:
``pacman -S helix``

### Linux:

- Debian-based distros (including Ubuntu-based):
``sudo apt install clang lldb git``
If using Helix:
``sudo apt install helix``

- Red-Hat based distros like Fedora:
``sudo dnf install clang lldb git``
If using Helix:
``sudo dnf install helix``

- Arch-based distros:
``sudo pacman -S clang lldb git``
If using Helix:
``sudo pacman -S helix``


### MacOS:

You can install Homebrew to easily install Clang and LLDB on linux. You could also install the Apple offical versions but they might have parts missing for what we use in this tutorial.

<https://brew.sh>

Once it is installed, use these commands in the Terminal.

``brew install llvm``
``brew install git``

If using Helix:
``brew install helix``

---

After installing, regardless of what OS you used, you will need to run these in the terminal to check it all worked:

``clang --version``
``lldb --version``
``git --version``

Each should display a notice containing the version information.


You can test if helix is installed by typing
``hx --version``
