### Setting up the C language on your computer

In this chapter you will be walked through the steps of setting up your computer for programming in C. There are separate instructions for different systems. 

A *compiler* is a tool that turns your code into machine code. Traditionally there are multiple steps. I will list them but they will be explained later on.

preprocessing
compilation
assembly
linkage

Most modern "compilers" actually do all of these steps together.

We will use a compiler called Clang. This is a compiler built on LLVM which is a tool that generates optimized machine code from a special in-between language.

## Windows

There are many options for using Clang on Windows. I recommend either using Windows Subsystem for Linux (WSL) or MSYS2.

WSL is a tool that lets you run Linux inside Windows! You can install it by typing into the PowerShell:

``wsl --install``

This will install a linux distribution (distro) called Ubuntu.

Then, restart your computer, open a PowerShell, type ``wsl`` to start WSL, and follow the steps for Debian-based distros

MSYS2 is an alternative to using WSL that sets up a linux-like , self-contained environment that is compatible with most Linux applications. You can install it from:

<https://www.msys2.org/>

And then follow the steps for Arch-based distros.

## Linux

Most linux distros come with a package manager that you can use in the terminal to install a compiler. I recommend Clang.

Type one of these into the terminal

Debian-based distros:
``sudo apt install clang``

Red-Hat based distros:
``sudo dnf install clang``
or
``sudo yum install clang``

Arch-based distros:
``sudo pacman -Syu clang``

## MacOS

You can download Clang as part of the whole LLVM kit from <https://releases.llvm.org/>
